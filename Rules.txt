Правила сообщества GitHub
1. Будьте открыты к новичкам

Каждый день на GitHub приходят новые пользователи — от тех, кто только создал свой первый проект, до опытных разработчиков. Относитесь с пониманием к разным уровням опыта и идеям .
2. Уважайте других

Критикуйте идеи, а не людей. Делитесь конструктивными замечаниями, будьте вежливы. Если не можете вести себя уважительно — лучше сделайте паузу .
3. Проявляйте эмпатию

GitHub — это глобальное сообщество с людьми разного происхождения, культуры и взглядов. Старайтесь понять чувства других, прежде чем реагировать .
Что запрещено (Acceptable Use Policies)
1. Активные вредоносные программы и эксплойты

Запрещено размещать или распространять вирусы, трояны, эксплойты, а также использовать GitHub для управления вредоносным ПО .
2. Издевательства и домогательства

Запрещены личные нападки, травля, преследование других пользователей .
3. Нарушение работы других пользователей

Нельзя намеренно мешать работе других — спамить, флудить, создавать помехи .
4. Доксинг и нарушение приватности

Запрещено публиковать чужую личную информацию (адреса, телефоны, документы) без согласия .
5. Разжигание ненависти и дискриминация

Запрещены высказывания, разжигающие ненависть по признаку расы, пола, религии, ориентации и т.д. .
6. Имперсонация (выдача себя за другого)

Нельзя выдавать себя за других людей или компании без их разрешения .
7. Недостоверная информация и дезинформация

Запрещено распространять заведомо ложную информацию, причиняющую вред .
8. Сексуально откровенный контент

Запрещены порнография, непристойный контент, сексуальные материалы без согласия (NCII) .
9. Угрозы насилия и жестокий контент

Запрещены угрозы физической расправой и неоправданно жестокие материалы .
10. Терроризм и экстремизм

Запрещен контент, связанный с террористическими организациями или экстремистской деятельностью .
Специальные ограничения для некоторых функций GitHub
GitHub Actions

Запрещено использовать Actions для :

    Майнинга криптовалют

    Попыток несанкционированного доступа к сервисам

    Нагрузки на серверы, несоразмерной пользе

    Любых действий, не связанных с разработкой ПО

GitHub Codespaces

Запрещено использовать Codespaces для :

    Майнинга криптовалют

    Хостинга продакшен-приложений

    Использования как CDN

    Любых действий, не связанных с разработкой и тестированием

Что делать, если нарушили ваши права

Если вы столкнулись с нарушением правил:

    Используйте инструменты модерации — блокировка пользователей, блокировка обсуждений, ограничение взаимодействия

    Сообщите о нарушении в службу поддержки GitHub через портал

    Если ваш контент или аккаунт был ограничен — вы можете подать апелляцию через специальную форму 

Важно понимать

Эти правила — не просто формальность. GitHub активно следит за их соблюдением и может:

    Удалить проблемный контент

    Заблокировать или отключить аккаунт

    Ограничить доступ к функциям

Нарушения серьезных пунктов (например, размещение вредоносного ПО или угрозы насилия) могут привести к немедленной блокировке без предупреждения .

Коротко: GitHub — это место для совместной разработки кода. Будьте вежливы, не вредите другим, не размещайте незаконный контент и не используйте функции платформы для посторонних целей. Все остальное — приветствуется! 🚀
